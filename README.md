# Ejercicios Básicos de HTML, CSS y JavaScript

Este repositorio reúne una colección de ejercicios prácticos simples diseñados para reforzar los fundamentos del desarrollo web frontend: maquetación semántica con HTML5, diseño y estilos con CSS3, e interactividad con JavaScript básico.

---

## Objetivos de Aprendizaje

* **HTML5:** Estructuración semántica, creación de formularios y manejo de elementos básicos.
* **CSS3:** Aprendizaje de estilos básicos, comportamiento de clases e ids.
* **JavaScript:** Fundamentos del lenguaje y creación básica de funciones.
