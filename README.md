# Ejercicios Básicos de HTML, CSS y JavaScript

Este repositorio reúne una colección de pequeños ejercicios prácticos diseñados para reforzar los fundamentos del desarrollo web frontend: maquetación semántica con HTML5, diseño y estilos con CSS3, y manipulación del DOM e interactividad con JavaScript básico.

---

## Objetivos de Aprendizaje

* **HTML5:** Estructuración semántica, creación de formularios y manejo de elementos básicos.
* **CSS3:** Modelo de caja, Flexbox, estilos dinámicos y manejo de selectores.
* **JavaScript:** Manipulación del DOM, lectura de eventos (`click`, `input`, `submit`), condicionales y funciones esenciales.
